Local tools and site capabilities

Every value entered on this page stays in this browser unless you explicitly download an export. The page has no server inbox, credential vault, background service, installer access, or authority over the installed game.

Static-site boundary: controls below perform only the browser-safe work they label. Unsupported native operations remain visible with the exact missing capability; they never simulate success.

Status

Update behavior

This site updates when a new deployment is loaded or the page is refreshed. It cannot inspect, download, stage, restart, or update the installed application. The installed Windows build uses its own unsigned Squirrel.Windows update path and must report those states inside the application.

Personal vocabulary JSON

Accepts a local JSON file up to 128 KiB using schema {"version":1,"replacements":{"original":"preferred"}}. Parsing rejects duplicate keys, unsafe object keys, unsupported fields, more than 256 entries, and oversized text. Only elements explicitly marked personalizable are changed.

        Troubleshooter
        1. Install and start Ollama using its official installer outside this site.
        2. Confirm http://127.0.0.1:11434/api/version responds locally.
        3. If the service is healthy but this page is blocked, configure Ollama's documented allowed origins for this exact site origin.
        4. Return here and retry. This page never changes service configuration.

          Local TOTP authenticator

          Generates RFC 6238 codes in this browser from a manually supplied otpauth://totp/ URI. Browser storage is not an operating-system credential vault, so persistent secret storage is intentionally disabled. The URI exists only in page memory and is cleared on reload.

          No authenticator entry loaded.

          QR import uses the browser's BarcodeDetector API when available. QR generation and camera scanning are unavailable in this static build and are not simulated.

              Bulk-close boundary

              A static documentation site has navigation destinations, not closable document tabs. “Close tabs containing text” and its inverse therefore cannot truthfully operate here. The installed application must provide the real preview, pinned/locked exclusions, unsaved-work handling, and close result.

                Notification centre

                Explicit browser-local limitations

                • No server inbox, authenticated status delivery, background worker, or cross-device synchronization.
                • No operating-system credential vault, application-data folder, local Git repository, installed editor detection, or direct file-manager launch.
                • No safe arbitrary local process launch, command execution, installer/update control, Ollama harness launch, or automatic rollback.
                • No bundled PDF, audio, video, archive, or spreadsheet adapter. Those catalog entries stay visible and disabled.
                • No durable unlimited queue: browser memory, picker, quota, and lifecycle limits remain real.
                • No dim-sum photograph or catalog is bundled, so this static site does not run the 10% startup draw. It does not generate, copy, fetch, or invent a dish or image; the complete surprise remains an explicit missing capability.
                • No real screenshot evidence can be created by this page. Captures must come from the built application through the approved headless route.
