## Visual evidence boundary

The repository contains one real packaged-application capture:
[`meadowmark-packaged-terrain-fields.png`](./assets/captures/meadowmark-packaged-terrain-fields.png).
It was captured from the installed build associated with commit
[`c328d7d`](https://github.com/Ding-Ding-Projects/meadowmark/commit/c328d7d3552aa46f22766de9d5bf763cdfe15bc1).
It shows terrain, field beds, the crop selector, navigation rail, and HUD state.
It does not prove every panel, service, interaction, accessibility path, narrow
layout, update path, or the final release candidate.
